# Аутсорс персонала

Сайт: https://autsorssite.ru/

## Автоматическое обновление

Сайт публикуется из ветки `main`. Измените `index.html`, `styles.css`, `script.js` или файлы в папке `assets/`, затем отправьте commit в `main` либо влейте pull request. Изменения обычно появляются на сайте через 1–2 минуты.

Новые изображения, шрифты и дополнительные ресурсы размещайте в `assets/`. Другие файлы из корня репозитория автоматически не публикуются. README не входит в публичную папку сайта.

Перед публикацией проверяются синтаксис JavaScript и наличие локальных ресурсов HTML/CSS. При технической ошибке сохраняется предыдущая рабочая версия. Проверки не оценивают правильность текста и дизайна.
